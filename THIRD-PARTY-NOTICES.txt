## 一、捆绑的第三方可执行文件与库

以下组件以独立文件形式随 relay 产物（Linux tar.gz / Windows zip / 桌面 NSIS）分发。
它们以**独立进程**（easytier-core）或**运行时动态加载的库**（wintun.dll / Packet.dll /
WinDivert64.sys）形式使用，不与 TokenNode 代码静态链接。

### 1.1 EasyTier（`easytier-core`）

| 项目 | 内容 |
|---|---|
| 用途 | 虚拟组网数据面（relay spawn 的独立子进程） |
| 捆绑版本 | 2.6.4-8428a89d |
| 来源 | https://github.com/EasyTier/EasyTier |
| 版权 | Copyright (C) EasyTier 项目贡献者 |
| 许可 | **GNU Lesser General Public License v3.0 (LGPL-3.0)** |

使用形式：relay 通过 `spawn` 调用 `easytier-core` 子进程并经本机参数通信，属
LGPL-3.0 意义上的「使用库的接口」而非「基于库的衍生作品」。依 LGPL-3.0 要求，
本文件附许可全文（见第五节），并告知组件的完整源码获取地址（上述来源）。
用户可自行以兼容版本的 `easytier-core` 替换产物中同名文件。

### 1.2 wintun（`wintun.dll`）

| 项目 | 内容 |
|---|---|
| 用途 | Windows TUN 虚拟网卡驱动（运行时由 easytier-core 动态加载） |
| 来源 | https://www.wintun.net/ （源码：https://git.zx2c4.com/wintun/） |
| 版权 | Copyright (C) 2018-2021 WireGuard LLC. All Rights Reserved. |
| 许可 | **Wintun Prebuilt Binaries License**（专有许可，非开源） |

**重要说明**：`wintun.dll` **源码**为 GPLv2，但其**预编译二进制**单独以
「Prebuilt Binaries License」发布。该许可第 3(d) 条明确允许在以下条件下随其他软件分发：

> d. resell, redistribute, lease, rent, transfer, sublicense, or otherwise
>    transfer rights of the Software without the prior written consent of
>    WireGuard LLC, **except insofar as the Software is distributed alongside
>    other software that uses the Software only via the Permitted API**;

TokenNode 通过 `wintun.h` 声明的 API（Permitted API）动态加载 `wintun.dll`，未修改、
未反向工程该库，符合上述例外条件。许可全文见第五节。

## 三、已捆绑（CLIProxyAPI，ADR-0035 决策 3）

### 3.1 CLIProxyAPI（`cli-proxy-api[.exe]`）

| 项目 | 内容 |
|---|---|
| 用途 | B 侧执行层（sidecar 独立进程，承载 claude / codex / antigravity 的 OAuth 调用与凭据刷新） |
| 来源 | https://github.com/router-for-me/CLIProxyAPI |
| 捆绑版本 | v7.3.4（初始 pin，见 `docs/deploys/cpa-sidecar.md` §平台矩阵；后续跟随策略属 ADR-0035 待定 2） |
| 版权 | Copyright (c) 2025-2005.9 Luis Pater；Copyright (c) 2025.9-present Router-For.ME（上游 `LICENSE` 前五行**原文照录**，其中「2025-2005.9」的年份区间系上游原始写法，非转抄错误） |
| 许可 | **MIT** |

使用形式：**独立进程**——`cpa.enabled=true` 时由 relay 托管（同目录定位 → spawn → 健康探活 →
退避守护），不与 TokenNode 代码静态链接，也不嵌入本仓库的 Go 二进制。

分发要求（MIT 的满足方式）：随产物保留版权声明与许可全文，故：

- 许可全文随产物以 `CLIPROXYAPI-LICENSE.txt` 分发（本文件亦附全文，见第五节之后的 3.1 全文附录）；
- 源码获取地址即上表「来源」。

平台矩阵：Linux（VPS 裸二进制）与 Windows（桌面 NSIS / dsh 插件包）三通道随产物捆绑；
**Android 通道按 ADR-0035 待定 6 方案 A（推迟）不捆绑**——Android 无 `/etc/resolv.conf` 且
relay 的进程内解析器（`TN_RESOLVER`）不传导给第三方子进程，内核在该环境无法解析上游域名；
收益（该通道现为免费模型分享形态、不供给三个 OAuth provider）不成立。详见
`docs/deploys/cpa-sidecar.md`。
